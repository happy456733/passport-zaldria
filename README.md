A deterministic Python program that draws an invented passport spread for the Republic of Zaldria — a fog-bound North Atlantic island nation — as a single PNG: a data page with a portrait and a machine-readable zone, and a stamps page with a consistent travel history. All text is rendered in code; the portrait is a generated passport photograph.

## Run it

```sh
python3 main.py
```

The image is written to `out/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set). It runs with zero network requests and is fully deterministic: two runs produce byte-identical output.
